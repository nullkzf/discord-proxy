**Download `DiscordProxy-Setup-….exe`**, run it, then open **Discord Proxy** from the Start menu or desktop instead of the normal Discord icon.

- No administrator rights needed. Windows 10 and 11 (64-bit; also runs on Windows on ARM through its x64 emulation).
- The installer is not code-signed, so Windows SmartScreen may say "Windows protected your PC": click **More info**, then **Run anyway**.
- `DiscordProxy-…-portable.zip` is the same program without an installer. `SHA256SUMS.txt` lists the checksums of both files.
- Unofficial; not affiliated with Discord Inc. See the README for what it does, its limits and how to remove it.
